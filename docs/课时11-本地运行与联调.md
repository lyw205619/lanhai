# 课时 11：本地运行与联调

## 学习目标

1. 列出 **完整中间件清单** 及 **推荐版本**（MySQL 8、Redis 6+、Nacos 2.x 等）。  
2. 按 **依赖顺序** 写出 **启动 checklist**（可复制到备忘录）。  
3. 在 **IDEA** 中配置 **多 Spring Boot 运行配置** 与 **Compound** 一键启动思路。  
4. 使用 **Nacos 控制台**、**Redis CLI**、**MySQL 客户端** 做 **最小验证**。  
5. 根据 **现象** 查 **排错表** 定位 **503、连接拒绝、登录失效**。

---

## 1. 环境清单（Windows 示例）

| 组件 | 作用 | 安装提示 |
|------|------|----------|
| **JDK 17** | 编译运行 | IDEA 内置下载或 Adoptium |
| **Maven 3.6+** | 构建 | IDEA Bundled Maven 或本机 `D:\xxx\mvn.cmd` |
| **MySQL 8** | 业务库 | 创建库 **`db_lanhai`**，导入 **[db/schema.sql](../db/schema.sql)**（详见 **[db/README.md](../db/README.md)**） |
| **Redis** | 网关 Token、业务缓存 | **本机 6379** 或 Docker |
| **Nacos 2.x** | 注册中心 | **8848**；**单机模式** 开发够用 |
| **MinIO** | 管理端上传 | **9000**；可选 **Console 9001** |
| **Ollama**（可选） | **service-ai** 转发本地大模型 | 默认 **11434**；需 **`ollama serve`** 且 **`ollama pull`** 与配置 **一致的模型** |

**专项文档**：架构、网关路由、鉴权与 **`curl` 示例** 的完整说明见 **[课时13-AI助手与Ollama接入.md](课时13-AI助手与Ollama接入.md)**。

## 2. 构建步骤

在 **`lanhai` 根目录**（含父 `pom.xml`）：

```bash
mvn clean install -DskipTests
```

**首次** 或 **大改依赖后** 必做；**仅改某个服务代码** 时可用 **IDEA Build** 加速迭代。

---

## 3. 启动顺序（推荐）

| 顺序 | 进程 | 说明 |
|------|------|------|
| 1 | **MySQL** | 库表就绪 |
| 2 | **Redis** | 网关鉴权依赖 |
| 3 | **Nacos** | **必须先于** 微服务与网关 |
| 4 | **MinIO** | 仅测上传时 |
| 5 | **五业务服务** | 可 **只起当前调试** 相关 |
| （可选） | **service-ai 8516** | 需 **Ollama**；见 `lanhai-service/service-ai` 的 **`lanhai.ollama`** |
| 6 | **Gateway 8500** | C 端入口 |
| 7 | **Manager 8501** | 后台 |

**原因简述**：**无 Nacos** → **lb 无实例**；**无 Redis** → **鉴权全失败**。

## 4. IDEA 实操

### 4.1 导入工程

**Open** 父目录 `lanhai` → **Maven** 自动识别 → **Reload Project**。

### 4.2 运行配置

对每个 `*Application.java`：**Run** → **Edit Configurations** → **Spring Boot**，**Main class** 选对，**Module classpath** 选对（如 `lanhai-server-gateway`）。

### 4.3 Compound（可选）

**Run → Edit → + → Compound**：添加 **executor 顺序**（先子服务后网关），**一键启动**。**注意**：**仍要保证** 中间件已起。

### 4.4 VM options（可选）

```text
-Dspring.profiles.active=dev
```

## 5. 验证手段

| 验证项 | 操作 |
|--------|------|
| **Nacos** | 浏览器 **8848**，**服务列表** 有 **service-product** 等 |
| **Redis** | `redis-cli ping` → **PONG** |
| **网关** | `curl http://localhost:8500` 或访问 **Swagger**（若有） |
| **直连服务** | `http://localhost:8511` 等（**仅调试**） |
| **AI（经网关）** | `POST http://localhost:8500/api/ai/chat`，body：`{"message":"你好"}`（需 **service-ai** 已注册、**Ollama** 已就绪） |
| **AI（直连 service-ai）** | `POST http://localhost:8516/api/ai/chat`（同上，**绕过网关** 仅本地调试用） |

## 6. 排错表（加长版）

| 现象 | 排查步骤 |
|------|----------|
| **503 / No instances** | Nacos **是否有服务**；**服务名** 是否与 **lb://** 一致；**健康检查** 是否失败 |
| **连接拒绝 8848** | Nacos **是否启动**；**防火墙** |
| **登录后仍 401** | **Redis** 是否有 **`user:lanhai:token`**；**Header 名** 是否 **`token`** |
| **数据库错** | **URL**、**账号**、**库名**；**时区** `serverTimezone` |
| **支付宝失败** | **沙箱密钥**；**notify 外网**；**签名类型** |
| **AI 超时 / 连接失败** | **Ollama** 是否监听 **11434**；**模型名** 是否与 `application-dev.yml` 中 **`lanhai.ollama.model`** 一致；本机 **`ollama list`** 核对 |

---

## 7. 本课小结

- **微服务本地** = **中间件先行 + 顺序启动 + 会看 Nacos**。  
- **排错** 先 **分层**：**网络 → 注册 → 路由 → 业务**。
