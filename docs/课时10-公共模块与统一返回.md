# 课时 10：公共模块与统一返回

## 学习目标

1. 能口述 **lanhai-common** 三个子模块 **各自职责**，并说明 **谁依赖谁**。  
2. 理解 **`Result<T>`** 与 **`ResultCodeEnum`** 的 **典型字段**（code、message、data）。  
3. 说明 **`GlobalExceptionHandler`** 处理的 **异常类型** 与 **返回 JSON 结构**。  
4. 找到 **Knife4j** 的 **标题配置** 类，并说明 **各服务** 如何 **复用或覆盖** 文档信息。  
5. 理解 **`@EnableLogAspect` + `LogAspect`** 的 **AOP 切入点**（如 **Controller**）。

---

## 1. common 三层结构

### 1.1 common-util

- **纯工具**：日期、字符串、ID 生成等（以包内类为准）。  
- **依赖**：尽量少，**避免** 引 **Spring Web**。

### 1.2 common-service

- **全局异常**：`GlobalExceptionHandler` — **@RestControllerAdvice** 捕获 **业务异常**、**参数校验** 等。  
- **统一返回**：`Result`、`ResultCodeEnum`（定义在 **lanhai-model** 或 common，以仓库为准）。  
- **Knife4j**：`Knife4jConfig` — **OpenAPI3** 分组、**文档标题「蓝海商城 API」** 等。

### 1.3 common-log

- **`@Log`** 注解 + **`LogAspect`** — **记录操作人、方法、参数**（注意 **脱敏**）。  
- **`@EnableLogAspect`** — **开关** 引入 **切面**。

---

## 2. 统一返回体（面试常画）

典型结构：

```json
{
  "code": 200,
  "message": "ok",
  "data": { }
}
```

| 字段 | 含义 |
|------|------|
| **code** | **业务码**（可与 HTTP 状态 **解耦**） |
| **message** | **人类可读** 说明 |
| **data** | **载荷**；失败时可为 **null** |

**网关鉴权失败** 也使用 **`Result.build`**，保证 **前端解析逻辑一致**。

---

## 3. 全局异常处理

**价值**：

- **避免** 栈信息 **直接暴露** 给前端。  
- **统一** **错误码**，便于 **监控告警**。

**扩展**：**参数校验** `@Valid` + **`MethodArgumentNotValidException`** 统一 **拼接 message**。

---

## 4. Knife4j / OpenAPI

- **依赖**：`knife4j-openapi3-jakarta-spring-boot-starter`（Spring Boot 3 **jakarta** 命名空间）。  
- **访问**：通常 **`/doc.html`**（Knife4j 默认）或 **Swagger UI**（视配置）。  
- **维护**：**Controller** 上 **`@Operation`、`@Parameter`** 注解 **与代码同步**。

---

## 5. 日志切面注意点

| 点 | 说明 |
|----|------|
| **敏感字段** | **密码、token** 需 **脱敏** |
| **性能** | **大对象** **toString** 可能 **撑爆日志** |
| **异步** | 高 QPS 可 **异步写日志** |

---

## 6. 本课小结

- **common** = **横切能力** 的 **沉淀**。  
- **Result + 异常 + 文档 + 日志** = **工程化** 的 **门面**。

---

## 7. 自测与扩展

1. **故意** 在 Controller **抛** `RuntimeException`，观察 **响应 JSON** 与 **HTTP 状态**。  
2. **对比** **网关** 与 **业务服务** 的 **错误体** 是否 **同结构**。  
3. **扩展**：阅读 **Problem Details**（RFC 7807）与 **统一返回** 的 **关系**。
