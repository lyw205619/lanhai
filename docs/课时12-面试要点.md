## 1. 项目介绍模板（可直接背，再口语化）

> **蓝海商城** 是我用 **Spring Cloud Alibaba** 做的一个 **微服务电商后端**。对外用 **Spring Cloud Gateway** 做 **统一入口**，业务按 **商品、用户、购物车、订单、支付** 拆成多个服务，全部注册到 **Nacos**；网关用 **Redis** 做 **Token 登录态** 校验。支付对接 **支付宝**，**异步通知验签** 后更新本地订单。另外有一个 **独立的管理端**，用 **Spring MVC** 做 **RBAC 权限** 和 **MinIO 文件上传**。技术栈是 **Spring Boot 3、Java 17、MyBatis、Redis**。

**可选一句（有 AI 需求时）**：另加 **service-ai**，经网关 **`/api/ai/**`** 把对话请求 **HTTP 转发到本机 Ollama**（本地 LLM，不依赖公网 API）。

**根据岗位删减**：偏 **中间件** 可强调 **Gateway + Nacos**；偏 **业务** 可强调 **订单与支付链路**。

## 2. 高频问答（要点）

### Q1：为什么用微服务？

**答**：**按业务域拆分**，**独立扩容**（如大促扩订单与支付）；**故障隔离**（支付服务异常不一定拖死商品浏览）。代价是 **运维与联调成本** 上升，所以 **本地用 Nacos + 网关** 把链路跑通。

### Q2：Gateway 做了什么？

**答**：**路由**（Path → lb://服务名）、**全局鉴权**（匹配 `/api/**/auth/**` 时校验 **Header token + Redis**）、**CORS**。**不负责** 细粒度 **RBAC**（在管理端或业务内）。

### Q3：服务怎么发现？

**答**：各服务 **`spring.application.name`** 注册到 **Nacos**；网关 **`lb://service-product`** 经 **LoadBalancer** 选实例。

### Q4：登录态怎么存？

**答**：**Token** 请求头；**Redis** 键 **`user:lanhai:{token}`** 存 **用户 JSON**。登出或踢人可 **删键**。

### Q5：分布式事务怎么做？

**答**：**诚实**：若 **同库** 可能 **本地事务**；若 **分库** 可用 **Seata**、**消息最终一致**、**TCC**。结合 **自己项目** 实际实现说，**没做** 就说 **可扩展方向**。

### Q6：支付为什么以异步通知为准？

**答**：**同步跳转** 可被 **用户关闭页面** 打断；**支付宝以 notify 为准** 更新 **支付成功**；必须 **验签 + 幂等**。

### Q7：和单体比缺点？

**答**：**网络延迟**、**分布式问题**（超时、重试、一致）。**团队小** 时 **单体更简单**；**学习/展示** 用微服务 **更有话题**。

### Q8：你如何调试？

**答**：**Nacos 看注册**；**各服务日志**；**直连端口** 绕过网关 **定位**；**Postman** 带 token。

### Q9：如果 QPS 很高怎么优化？

**答**：**无数据不编**：可说 **缓存**、**读写分离**、**消息削峰**、**网关限流** —— **结合场景** 展开。

### Q10：你负责哪些模块？

**答**：**按真实** 回答（**全栈自己搭** 也可以说），**忌虚构团队分工**。
