# 蓝海商城（lanhai）课程文档索引

本目录对 **lanhai** 微服务项目做 **系统化、可自学、可面试复述** 的讲解。体例与深度目标：对齐 **`java_job_scheduler/docs`**、**`reactor_http/docs`** 中的「学习目标 → 分节讲解 → 与源码对应 → 易错点 → 小结 → 自测与扩展」。

## 阅读顺序（建议）

| 轮次 | 建议顺序 | 目的 |
|------|----------|------|
| **第一遍** | 01 → 03 → 05 → 06 | 建立 **全局架构 + 入口 + 鉴权 + 业务拆分** |
| **第二遍** | 02 → 04 → 10 | 搞清 **Maven、Nacos/Feign、公共模块** |
| **第三遍** | 07 → 08 → 09 | 深入 **业务链路、支付、管理端** |
| **答辩前** | 11 → 12 | **本地联调、面试话术、表述边界** |
| **AI 专项** | **13** | **service-ai、Ollama、网关路径、鉴权与联调** |

## 前置知识

- **Java**、**Spring Boot**、**HTTP**、**JSON**、**MySQL 基础**。  
- **不必**预先精通 **Spring Cloud**：可按课时顺序边查边学。
